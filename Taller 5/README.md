# Taller Fetch - Libreria

## Objetivo del Taller
- Implementar Fetch API para consumir datos
- Crear un paginador funcional
- Manipular el DOM dinámicamente
- Manejar parámetros de URL

## Actividad 1: Fetch API
1. Crea una función asíncrona para obtener los libros
2. Implementa el llamado a la API usando Fetch
3. Agrega manejo de errores usando try/catch
4. Verifica la respuesta de la API en la consola

## Actividad 2: Implementación del Paginador
1. Crea la estructura del paginador con 4 botones
2. Implementa la lógica para cambiar de página
3. Agrega el estado activo al botón de la página actual
4. Asegúrate que al cambiar de página:
    - Se actualicen los libros
    - Se actualice el estado del paginador
    - Se mantenga el estado visual

## Actividad 3: Mejoras y Pruebas
1. Agrega validaciones para:
    - Datos faltantes
    - Errores de red
    - Límites de página
2. Prueba la navegación entre páginas
3. Verifica que se muestren 15 libros por página
4. Comprueba que el paginador funcione correctamente

## Entregables
- Código fuente completo
- La aplicación debe:
    - Mostrar 15 libros por página
    - Permitir navegar entre 4 páginas
    - Mantener un diseño responsivo
    - Manejar errores apropiadamente

## Criterios de Evaluación
- Funcionamiento correcto del Fetch API
- Implementación adecuada del paginador
- Manejo de errores
- Estructura y organización del código
- Diseño responsivo y usabilidad
