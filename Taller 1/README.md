# Clase 4 – Taller Práctico de HTML 
> Temática: Construcción de una página web personal estructurada

## Objetivo del Taller
Aplicar los conceptos vistos en clases anteriores creando una página web personal que incluya estructura semántica, un formulario con validación básica y una tabla con datos.

## Descripción del Reto
Vas a desarrollar tu propia página web personal que incluya: información básica sobre ti, una sección con tus intereses o proyectos, un formulario para que los visitantes puedan contactarte y una tabla con datos relevantes (por ejemplo, tu calendario de actividades o habilidades).

**Meta**: Crear un HTML bien estructurado, fácil de leer y con buen uso de etiquetas semánticas.

## Requisitos Mínimos
- Formulario con validación básica: nombre, email, mensaje (usar required, type='email', minlength).
- Tabla con datos: mínimo 3 columnas y 3 filas
- Uso correcto de atributos alt en imágenes.

## Sugerencia de Estructura – Wireframe

```
------------------------------------------------------
|                       HEADER                       |
|                [Tu nombre / Título]                |
------------------------------------------------------
|  NAV | Inicio | Sobre mí | Proyectos | Contacto    |
------------------------------------------------------
| MAIN:                                              |
|       SECTION: Sobre mí                            |
|           Imagen tuya + breve descripción          |
|                                                    |
|       SECTION: Tabla de habilidades                |
|           [Tabla con 3-4 filas y columnas]         |
|                                                    |
|       SECTION: Formulario de contacto              |
|           [Nombre] [Email] [Mensaje] [Enviar]      |
------------------------------------------------------
| FOOTER: © 2025 Tu Nombre – Todos los derechos      |
------------------------------------------------------
```

## Buenas Prácticas
- Usa indentación consistente (2 o 4 espacios).
- Cierra siempre las etiquetas.
- Organiza el HTML en secciones lógicas.
- Nombra archivos e imágenes en minúsculas y sin espacios (usa guiones o guiones bajos).
- Comenta partes importantes de tu código.
- Verifica tu HTML con herramientas como W3C Validator.
